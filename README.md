# Emergency Medical Information Card – FHIR

A practical HL7 FHIR R4 interoperability project built with
C#, ASP.NET Core, Blazor, and the Firely .NET SDK.

## Purpose

This project demonstrates how emergency medical information
can be represented using standardized HL7 FHIR resources.

The goal is to build an Emergency Medical Information Card
that can provide essential patient information in an
interoperable format.

## Implemented FHIR Resources

- Patient
- AllergyIntolerance
- Condition
- MedicationStatement
- Bundle

## Technology

- C#
- .NET
- ASP.NET Core
- Blazor
- HL7 FHIR R4
- Firely .NET SDK

## Current FHIR Model

Patient
- Allergies
- Medical conditions
- Current medications

These resources are combined into a FHIR Bundle.

## Project Status

Work in progress.

The project is being developed step by step as a practical
FHIR interoperability learning project.

## Disclaimer

All patient and clinical data used in this repository are
fictional and are intended for demonstration purposes only.
